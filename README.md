# Conformity Shield

This is a design for a Arduino Uno R3 compatible shield, that connects an RP2354B to all IO pins. It is inteded to be used to test implementations of [`embedded-hal`](https://docs.rs/embedded-hal/).

**Warning:** rev1 of this board has known problems, do not produce boards from this yet, see the issue tracker for details!
